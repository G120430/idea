温椿白

身份
时序守望者｜白昼秩序维系者，本源【灵】，以冬雪为素材诞生，执掌世界光明面，与温枫年互为昼夜搭档，日常称呼温枫年为姐姐。

外貌特征
有着如同冬日落雪一般的银白泛浅灰长发，发丝柔软松散、轻盈自然。肤色清透冷白，眼瞳是通透干净的淡紫色，如同冰封冰层之下静静凝住的一层紫雾，澄澈又温柔。左脸颊生有一颗浅淡的小痣，为素净清冷的面容添上独有的柔软标记。整体气质安静素冷，像旷野里无人惊扰、静静堆积的薄雪。专属代表色：霜白、浅灰、淡紫。

人物性格
在外人面前，永远是一副冷淡寡言的模样，自带生人勿近的清冷疏离气场，极少主动开口搭话、从不主动合群。但这份冷漠只是外在气场，绝非不善言辞。她本身逻辑清晰、表达流畅、十分擅长沟通，内心鲜活活泼、思绪跳跃，脑海里永远藏着源源不断的新奇想法。

她天生慢热且谨慎，不会轻易对陌生人敞开心扉，所有的活泼、健谈、热烈，只专属熟悉且完全信任的人。尤其面对姐姐温枫年时，周身冰冷外壳会彻底消融，变得格外健谈、松弛又热情，会主动滔滔不绝、火热畅快地闲谈，毫无保留地倾诉心底思绪、日常见闻与细碎小事。

背景设定
本源【灵】自凛冬落雪之中诞生，与生俱来执掌白昼秩序与世间光明。专属职责为稳住白昼时序、净化白日滋生的躁动杂念、稳固整片白昼边界，维系人间白日的安稳平和。

与温枫年形成完美昼夜分工：温枫年执掌黑夜、管控异象、回溯修补空间裂痕；温椿白守护白昼、稳定时序、净化光明区域躁动。二人昼夜相依、彼此兜底，共同维系整个主空间的平衡与安宁。

她无需伪装自己，清冷疏离是与生俱来的本色，不同于被迫外向的温枫年。冰雪是她温柔的保护屏障，她所有的鲜活、热忱、灵动与流利表达，只赠予自己认可、信赖、珍视之人。

人物细节

  • 代表意象：凛冬落雪，雪面寂静清冷，雪下藏着蓬勃鲜活的生机
  • 专属代表色：霜白、浅灰、冰淡紫
  • 面对陌生人与生人，始终沉默清冷、保持距离，绝不主动倾诉
  • 面对姐姐温枫年与亲信之人，彻底放开自我，话多活泼、畅所欲言
  • 被人真诚夸奖时不会害羞局促，只会安静接纳，淡紫色眼瞳会悄悄发亮
  • 动用光明力量、维系白昼秩序时，会显露【灵】之本相，紫瞳澄澈明亮、自带柔光
